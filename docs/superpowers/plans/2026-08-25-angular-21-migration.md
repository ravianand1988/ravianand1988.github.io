# Angular 17 → 21 Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move ravianand1988.github.io from Angular 17.3 to Angular 21.2, adopting built-in control flow, zoneless change detection, and the Vitest unit-test builder.

**Architecture:** Direct configuration rewrite rather than four sequential `ng update` hops. Every target config value is copied from a real `npx @angular/cli@21 new --style=scss --ssr=false` scaffold, not inferred. Viable because the app has zero dependency injection, no router, no services, and no NgModules — nine standalone components of static markup plus three typed data arrays.

**Tech Stack:** Angular 21.2, TypeScript 5.9, `@angular/build` (application + dev-server + unit-test builders), Vitest 4 with jsdom, SCSS, GitHub Pages via GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-25-angular-21-migration-design.md`

## Global Constraints

- **Target framework version:** `@angular/*` at `^21.2.0`; `@angular/cli` and `@angular/build` at `^21.2.18`.
- **TypeScript:** `~5.9.2`. Angular 21.2's peer range is `>=5.9 <6.1`; do not exceed it.
- **Node:** local must satisfy `^20.19.0 || ^22.12.0 || >=24.0.0`. Current local Node is v20.20.2 and is sufficient — do not upgrade it.
- **`outputPath` must remain `dist/ravianand1988.github.io`.** It is coupled to the artifact path `dist/ravianand1988.github.io/browser` in `.github/workflows/deploy.yml`. Changing one requires changing the other.
- **`anyComponentStyle` budget stays at 2kb warning / 4kb error.** The Angular 21 default relaxes this to 4kB/8kB; do not adopt the default. CLAUDE.md records the tighter budget as deliberate.
- **Assets stay in `src/assets/`.** Do not move to `public/` — it would change the served URL of `photo.jpg` from `assets/photo.jpg` to `photo.jpg`.
- **Component filenames stay `*.component.ts`.** Do not rename to the Angular 20 `app.ts` convention.
- **No Prettier, no linter.** The Angular 21 scaffold adds `.prettierrc` and a `prettier` devDependency; this repo has no formatter by choice. Do not add one.
- **One squashed commit.** Tasks 1–4 leave the working tree dirty on purpose. Only Task 5 commits.
- **Content accuracy:** this site states real employment history. No task in this plan may alter any user-facing copy, date, job title, or claim. Template rewrites must preserve text and interpolation bindings exactly.
- **Formatting:** 2-space indent, single quotes in TS, final newline, no trailing whitespace (per `.editorconfig`).
